A simple and interactive **Snake Water Gun** game built with Python. Play against the computer, test your choices, and see who wins!

This project demonstrates my understanding of Python fundamentals through a practical, playable application.

## 🎮 Game Preview

Choose one of the following options:

- 🐍 `s` — Snake
- 💧 `w` — Water
- 🔫 `g` — Gun

The computer randomly selects an option, and the game determines the result according to the rules.

## ✨ Features

- 🎲 Random computer choices using Python's `random` module
- ⌨️ User input for selecting a move
- ✅ Input validation for unsupported choices
- 🏆 Automatic win, lose, and draw detection
- 📟 Simple command-line interface
- ⚡ Lightweight and easy to run

## 📜 Game Rules

| Your Choice | Opponent's Choice | Result |
|---|---|---|
| Snake | Water | Snake wins |
| Water | Gun | Water wins |
| Gun | Snake | Gun wins |
| Same choices | Same choices | Draw |

**Note:** The computer's choice is random, so each round can produce a different result.

## 🚀 Getting Started

### Prerequisites

Make sure Python 3 is installed on your system.

Check your Python installation:

```bash
python --version
```

### Run the Project

**1. Clone or download the repository.**

**2. Open the project folder in VS Code.**

**3. Open the terminal and run:**

```bash
python main.py
```

On Windows, you can also use:

```bash
py main.py
```

Follow the on-screen instructions and enter `s`, `w`, or `g` to play.
