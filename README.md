## ⚡ Getting Started

Want to explore or run my projects locally?

### Prerequisites

- Python 3 installed on your computer
- Git installed on your computer

### Installation

**1. Clone this repository**

```bash
git clone https://github.com/devsatyarthupadhyay/Python-Projects.git
```

**2. Navigate to the project directory**

```bash
cd Python-Projects
```

**3. Open the repository in VS Code**

```bash
code .
```

**4. Navigate to a project folder and run its Python file**

For example, for Snake Water Gun:

```bash
cd "Snake Water Gun Game"
python main.py
```

*Note: On some systems, you may need to use `python3 main.py` instead.*
